## ✨ Sobre o Projeto

Este projeto é um sistema simples de **cadastro de funcionários**, desenvolvido em **C#** utilizando o framework **Windows Forms**. O objetivo principal foi criar uma aplicação de desktop funcional que permite a inserção, visualização e gerenciamento de dados de forma temporária.

O sistema armazena as informações dos funcionários **diretamente na memória do computador**, o que o torna um excelente exemplo para demonstrar conceitos de manipulação de dados, estrutura de classes e interações com a interface do usuário em uma aplicação de desktop.

🔹 Principais destaques:

* ✅ Desenvolvimento de uma aplicação **stand-alone** para desktop
* ✅ Interface de usuário (GUI) intuitiva para cadastro de dados
* ✅ Gerenciamento de dados **in-memory** (não persistente)
* ✅ Ótimo projeto para praticar a criação de formulários e manipulação de listas em C#
